# VocalForge downloads

Official download files for [VocalForge](https://fuidzy.com/vocalforge), the vocal workstation for Windows by Fuidzy.

These files are served through `downloads.fuidzy.com`. You normally never need this repository: download VocalForge from
https://fuidzy.com/vocalforge and the app fetches the optional AI add-on from here by itself, checking a SHA-256 for every file.

Files live in the [`downloads` release](../../releases/tag/downloads):

| File | What |
|---|---|
| `VocalForge-Setup-<version>.exe` | the Windows installer |
| `vocalforge-ai-cpu-1.zip` | optional AI vocal-separation add-on (works on any PC) |
| `vocalforge-ai-gpu-1.zip.001` / `.002` | the same add-on for NVIDIA GPUs, in two parts (the app joins them) |
| `manifest.json` | sizes and SHA-256 of every file, and the current app version |
